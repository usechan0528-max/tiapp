도메인 및 API. 먼저 실패하는 테스트를 작성하고 기존 업무 제출·권한·충돌 검사를 유지한다. 기존 src/lib/tasks, src/app/api/tasks/route.ts, Source.tsx와 tests/task-handoff.test.ts를 읽는다. 후속 담당자가 결과 제출 시 선행 업무의 구조화된 표 행을 하나 명시적으로 지정할 수 있게 하고 서버에서 선행 관계, 실제 행과 표시 버전을 검증한다. TSV와 마크다운 표를 지원한다. 기존 미연결 자료도 호환한다. 연결된 행의 변경이나 삭제를 판별하고 이동·다른 행만 수정 때 거짓 경보를 피한다. 식별이 모호할 때 조용히 다른 행에 연결하지 않는다. 해당 결과의 이전 근거와 최신 행, 처리 대상 버전을 반환한다. 원본 열람과 구분하여 후속 업무 담당자만 명시적으로 재확인을 완료할 수 있게 하고 동시 변경과 중복 처리에 안전하게 SQLite에 보존한다. 구현한 API 계약을 step summary에 기록한다. 단위 테스트에서 무관한 행, 재열람, 다른 사용자, 동시 변경을 검증한다.
