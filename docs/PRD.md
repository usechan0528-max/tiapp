# TF 프로젝트 에이전트 · 확정 MVP

## 누구의 어떤 문제를 푸는가

대학 팀 프로젝트와 회사의 임시 TF에서는 팀장이 진행 상황을 일일이 묻고, 다음 담당자에게 자료를 전달하고, 마지막에 결과물을 다시 모은다. 팀원은 자기 업무가 언제 시작되고 무엇을 제출해야 하는지 알고 싶다. 이 앱은 팀이 합의한 목표에서 최종 결과물까지 담당자와 자료의 흐름을 연결한다.

## 확정 기능과 인수 기준

| 기능 | 요구사항 | 사용자가 확인할 수 있는 결과 |
|---|---|---|
| TF 생성·초대 | 팀장은 목표와 마감일로 TF를 만들고 초대 링크를 공유한다. 팀원은 이름·역할·가능 일정을 입력해 합류한다. | 서로 다른 휴대폰에서 같은 팀을 보고, 같은 브라우저로 다시 열면 기존 멤버로 돌아온다. |
| 계획 제안·확정 | 실제 팀 구성에 맞춰 결과물 형태·완료 기준, 업무별 담당자·기한·선행 업무·제출 기준을 제안한다. 팀원 피드백을 반영한 변경점을 보여주고 팀장이 확정한다. | 팀원의 일정 제약이 수정안에 반영된다. 팀장이 확정한 버전에서만 배정이 시작된다. |
| 개인별 업무 배정 | 내 업무에서 지금 시작할 일과 필요한 자료를 확인한다. 선행 업무가 끝나면 후속 업무와 원본 제출물을 함께 전달한다. | 첫 담당자가 낸 표나 링크를 다음 담당자가 자기 업무 카드에서 연다. |
| 진척·막힘 확인 | 한 줄 체크인으로 마지막 보고, 막힌 이유, 영향을 받는 업무, 다음 확인 시점을 기록한다. 에이전트는 이전 보고를 근거로 앱에서 후속 질문을 건넨다. | 팀 전체가 누가 무엇을 기다리는지 확인한다. 답이 없으면 마지막 보고 시점을 유지한다. |
| 결과물 취합·검수 | 계획에서 합의한 구성으로 글·표·링크를 취합하고 원본을 연결한다. 누락이나 충돌은 해당 팀원에게 보완 요청한다. 팀장이 최종본을 확정한다. | 행사 팀은 시간대별 운영표를, 시제품 팀은 실행 링크와 검증 결과를 얻을 수 있다. 팀원 모두 같은 확정본을 연다. |
| 운영표 공동 보완 | 최초 제출 후 작성자와 직접 인계받은 담당자가 운영표를 수정한다. | 같은 버전에서 각각 수정하면 먼저 저장한 변경과 다른 사람의 초안이 모두 남는다. |

## 모바일 화면과 범위

TF 생성·참여, 계획, 업무판, 최종 결과물의 네 화면을 제공한다. 업무판은 내 업무와 팀 전체 보기로 전환한다. 첫 버전은 브라우저 세션으로 참여하고 앱 안에서 후속 질문을 받는다. 외부에서 제작한 시제품·영상은 제출 링크로 연결한다.

## 전체 인수 시나리오

A가 링크로 B를 초대한다. B의 일정 피드백을 반영한 계획을 A가 확정한다. B가 막힘을 보고한 뒤 후속 질문에 답하고 자료를 제출한다. A의 다음 업무에서 그 자료를 열 수 있다. A가 취합본을 확정하면 두 휴대폰 모두에서 최종본과 자료 출처가 열린다.

## 개인 팀 관리

한 사용자가 여러 팀에 참여할 수 있다. 개인 페이지에서 팀별 역할을 확인하고 새 팀을 만들거나 초대로 가입하며 활동할 팀을 선택한다.

## 운영표 인계와 수정 확인

선행 자료를 제출하면 후속 담당자가 열어 둔 업무판에 3초 안에 시작 가능 상태와 원본이 나타나는지 두 모바일 세션으로 검증한다. 담당자가 읽은 원본의 본문이나 링크가 바뀌면 해당 카드에 변경 사실을 표시하고 최신 버전을 열면 해제한다.

## 완료한 점검 결과 재확인

담당자는 점검 결과를 제출할 때 직접 인계받은 운영표에서 근거 행 하나를 선택할 수 있다. 다른 행만 수정하면 점검은 그대로 완료 상태다. 선택한 행이 바뀌거나 사라지거나 여러 행으로 겹치면 내 업무와 팀 전체의 완료 카드에 ‘다시 확인할 일 1건’이 뜬다. 담당자가 변경 사항과 제출한 결과를 대조하고 조치를 완료하면 양쪽에서 요청이 사라진다.

## 팀 채팅과 공유 노트

업무판에서 팀 채팅방을 연다. 같은 팀의 누구나 메시지를 보내고 지난 대화를 읽을 수 있다. 서버는 5분마다 새 대화를 확인하고 에이전트가 주요 논의, 결정 사항, 할 일, 미해결 질문을 정리한 공유 노트를 채팅방에 저장한다. 팀원은 나중에 합류해도 저장된 노트와 근거 메시지를 함께 열람한다. 정리 도중 도착한 대화는 다음 노트에 포함한다.
