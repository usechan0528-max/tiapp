# 모바일 업무 화면

팀원이 필요한 자료를 바로 찾도록 각 화면에 제목과 항목별 상태를 배치한다. 저장된 정보가 없는 항목은 ‘미등록’으로 표시한다.

안내 문구는 사용자가 다음 행동을 선택하거나 결과를 이해하는 데 필요할 때만 쓴다. 백엔드 처리 과정을 사용 팁이나 화면 설명으로 적지 않는다.

| 요소 | 기준 |
|---|---|
| 레이아웃 | 본문 최대 52rem, 좌우 여백 1~3rem. 제목과 상태 행을 왼쪽에 정렬한다. |
| 탐색 | 네 목적지를 하단에 고정한다. 각 링크 높이는 최소 56px이고 하단 안전 영역을 확보한다. |
| 현재 위치 | 녹색 상단 선, 굵은 글자, aria-current로 표시한다. |
| 색 | 배경 #f5f7f2, 기본 글자 #182e29, 강조 #176448, 구분선 #cad5cd |
| 글꼴 | 시스템 고딕. 화면 제목은 폭에 따라 2.2~3.5rem, 본문 줄 높이는 1.65다. |
| 상태 행 | 왼쪽에 항목명, 오른쪽에 값. 얇은 수평선으로 행을 구분한다. |
| 접근성 | 본문 바로가기, 키보드 초점 테두리, 한국어 문서 언어를 제공한다. |
| 동작 | 링크의 배경색으로 호버·누름에 응답한다. 탐색에 애니메이션을 요구하지 않는다. |

## 개인 팀 관리

공통 헤더의 ‘내 팀 관리’에서 팀별 마감일과 팀장·팀원 역할을 확인한다. 새 팀 만들기, 초대로 참여하기, 현재 팀 열기를 제공한다.

## 인계된 원본의 변경 표시

후속 업무 카드에서 열어 본 원본이 수정되면 ‘원본 열기’ 옆에 ‘원본 변경됨’을 표시한다. 담당자가 최신 원본을 펼쳐 확인하면 표시를 해제한다.

운영표 보완 폼은 오프라인 상태를 알리고 초안을 유지한다. 원본이 바뀐 상태에서는 저장을 막고 서버 최신본과 작성 중인 본문·링크를 함께 보여 준다.

운영표를 인계받은 담당자는 자료 제출 폼의 ‘근거 행’에서 한 행을 선택한다. 폼을 작성하는 동안 원본 버전이 바뀌면 이전 선택과 본문을 유지하고 최신 행을 다시 선택할 수 있게 한다.

완료 카드에 ‘다시 확인할 일 1건’이 뜨면 변경 전·후 행과 제출한 점검 결과를 세로로 배치한다. 각 표는 기존 머리글을 유지한다. 최신 행이 없으면 삭제 또는 중복 이유를 표시한다. 결과 담당자의 카드에 ‘조치 완료’ 버튼을 제공한다.

## 팀 채팅

업무판의 ‘팀 채팅’에서 현재 팀의 대화와 공유 노트를 연다. 대화에는 작성자·시각·본문을 표시한다. 공유 노트는 생성 시각으로 구분하고, 각 항목에 분류와 근거 메시지를 표시한다. 첫 노트가 생기기 전에는 자동 정리 주기를 안내한다.
